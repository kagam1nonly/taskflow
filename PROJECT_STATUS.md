## What Was Completed Recently (2026-04-28)

### Smart Drag & Drop
- Migrated from simple `useDraggable` to `@dnd-kit/sortable`.
- Implemented **natural reordering**: tasks now slide out of the way to show exactly where a dropped task will land.
- Fixed "jumping" behavior: Clicking a task no longer moves it to the bottom.
- Added backend position-shifting logic: moving one task now automatically updates the indices of all affected tasks in the column.

### Premium UI Polish
- **Context Menus**: Fixed stacking issues; menus now appear on top of all other cards and auto-close on mouse-leave.
- **AI Badge**: Tasks generated by Gemini now feature a prominent `✨ AI` badge.
- **Glassmorphism**: Enhanced backdrop-blur and semi-transparent layers for a modern "premium" feel.
- **Portals**: Raised modal z-index to 1000 to ensure full coverage over the board.

### Authentication & Resilience
- **Clock Skew Tolerance**: Added 60-second leeway and multi-algorithm (`HS256`, `RS256`, `ES256`) support to JWT decoding to prevent `401 Unauthorized` bugs.
- **Smart Redirects**: Fixed board-to-login routing when tokens expire.
- **Favicon & SEO**: Deployed official brand SVG as favicon and implemented OpenGraph metadata.

### AI Stability
- Updated to **Gemini 3.1/3.0 Preview** models to bypass new restrictive Free-Tier zero-quotas on stable `2.x` branches.
- Implemented intelligent model skipping for `404 Not Found` API deprecations.
- Implemented exponential backoff for 429 (Rate Limit) and 503 (Overload) errors.
- **External Monitoring**: Switched to UptimeRobot for service health checks (decommissioned internal self-ping logic).

## Deployment Notes
- **Database**: Managed PostgreSQL on Supabase (to prevent inactivity sleeping).
- **Environment**: Containerized via Docker Compose.
- **Security**: Supabase Auth (JWT) required for all board operations.
- **Scaling**: Redis-backed WebSockets allow for multiple backend instances.
